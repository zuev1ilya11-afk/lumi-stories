Политика конфиденциальности

Дата вступления в силу: 3 октября 2026 г.

Эта политика описывает, какие данные могут обрабатываться при использовании Telegram Mini App LUMI, зачем они нужны и какие возможности есть у пользователя.

1. Какие данные мы обрабатываем

При использовании LUMI могут обрабатываться следующие категории данных:

  • данные Telegram, переданные Mini App: идентификатор пользователя и доступные профильные данные, необходимые для входа и работы приложения;
  • игровой прогресс: открытые эпизоды, выбранные варианты, сюжетные флаги, состояние прохождения и связанные игровые параметры;
  • технические и аналитические события, необходимые для стабильной работы, диагностики ошибок и улучшения интерфейса;
  • данные о покупках через Telegram Stars: статус платежа, сумма в Stars и технические идентификаторы Telegram-платежа.

LUMI не получает и не хранит данные банковских карт. Оплата цифрового контента проводится средствами Telegram Stars.

2. Для чего используются данные

  • для авторизации пользователя внутри Telegram Mini App;
  • для сохранения и восстановления прогресса истории;
  • для предоставления купленного цифрового контента;
  • для предотвращения повторной обработки платежей, злоупотреблений и технических ошибок;
  • для анализа стабильности приложения и улучшения пользовательского опыта;
  • для обработки обращений в поддержку.

3. Где обрабатываются данные

Для работы LUMI используются сервисы Telegram, GitHub Pages и Supabase. Эти поставщики инфраструктуры могут обрабатывать технические данные в соответствии со своими условиями и политиками конфиденциальности.

4. Передача третьим лицам

Мы не продаём персональные данные пользователей. Данные могут передаваться только поставщикам инфраструктуры, необходимым для работы LUMI, либо когда раскрытие требуется законом.

5. Хранение данных

Данные хранятся столько, сколько необходимо для работы LUMI, сохранения прогресса, обеспечения безопасности и выполнения обязательств, связанных с платежами. Отдельные записи могут храниться дольше, если это требуется законом или необходимо для разрешения платёжных споров и предотвращения мошенничества.

6. Права пользователя

Пользователь может обратиться с запросом о доступе к своим данным, их исправлении или удалении, если применимое законодательство предоставляет такое право. Для обработки запроса может потребоваться подтверждение Telegram-аккаунта, к которому относятся данные.

7. Безопасность

LUMI использует серверную проверку данных запуска Telegram и ограничивает прямой доступ клиента к внутренним данным. При этом ни один способ хранения или передачи информации не может гарантировать абсолютную безопасность.

8. Дети

LUMI не предназначена для использования лицами младше минимального возраста, установленного применимым законодательством и правилами Telegram для самостоятельного использования сервиса.

9. Изменения политики

Политика может обновляться при изменении функций LUMI, способов обработки данных или требований законодательства. Актуальная версия всегда публикуется на этой странице.

10. Контакты

По вопросам конфиденциальности и удаления данных можно обратиться через Telegram: @lumi_history_bot.

Используя LUMI, пользователь подтверждает, что ознакомился с этой политикой.
